IMPORTANT STARTUP ISSUE:
MLB 2K12 freezes at the initial startup/title screen when the Windows
system date is outside the game's expected 2012 schedule/calendar logic.

PREFERRED LAUNCH METHOD:
D:\Xenia\Tools\MLB_2K12_Launcher\Launch_MLB_2K12.bat

Launcher Function:
1. Temporarily sets the Windows date to 09-30-2012.
2. Launches MLB 2K12 through Xenia.
3. Waits for Xenia to close.
4. Requests Windows time synchronization to restore the correct date/time.

Manual Fallback:
If the launcher is unavailable, manually set Windows to September 30, 2012,
launch and play MLB 2K12, then restore Windows automatic date/time afterward.

In-Game Settings Tested:
Autosave = Off
Living Rosters = Off

These settings did NOT eliminate the startup freeze when Windows remained
on the current 2026 date.

============================================================
EMULATOR BUILD POLICY
============================================================
1. Always test new games on the PRIMARY emulator first.

2. Always begin with the current known-good universal baseline.

3. Do not change settings preemptively.

4. Change ONE variable at a time during troubleshooting.

5. Record:
   - Original value
   - Tested value
   - Result
   - Final known-good value

6. Prefer per-game configuration solutions when a future title needs
   something incompatible with the universal baseline.

7. Create an alternate Xenia build ONLY if a game genuinely requires one.

8. Store alternate builds under:
   D:\Xenia\Alternative_Xenia_Builds\

9. Document exactly which game uses each alternate build in:
   - This Emulator Map
   - Xenia Baseline Configurations spreadsheet

10. Never sacrifice already-working games simply to accommodate another game.

11. After meaningful global configuration changes, regression-test existing
    known-good games when appropriate.
